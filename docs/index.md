Welcome to Skytable's documentation! Skytable is a modern distributed NoSQL database that builds on the foundations of performance, scalability, powerful querying and a robust type system. Skytable can be deployed on multiple platforms as just a single binary file with no special system dependencies. You can either follow the guide below to learn Skytable in depth or jump to any sections that you need for reference.

Skytable can either be deployed in single-node mode (i.e. one instance) or distributed mode (i.e. more than one instance). We recommend using Skytable as part of a distributed deployment.
